# Лісовий архів

Telegram-бот, що відповідає звірам на питання тільки за документами «Лісового архіву» і за порадами, які звірі надсилають файлами. Відповіді формує LLM з безкоштовного рівня Groq.

## Запуск

```bash
cp .env.example .env
# вписати TELEGRAM_BOT_TOKEN і GROQ_API_KEY
docker compose up --build
```

На старті бот застосовує міграції, імпортує архів із `data/archive/` і починає приймати повідомлення. Повторний імпорт пропускає файли, які вже є в базі.

## Скановані документи

19 PDF в архіві — скани без текстового шару. Для них у `data/transcripts/` лежать вивірені вручну транскрипти, прив'язані до sha256 файлу (`manifest.json`). Якщо файл змінився або звір надіслав новий скан, текст розпізнає OCR (tesseract, мова `ukr`). Транскрипти потрібні тому, що OCR на фоні «береста» плутає цифри, наприклад «350 кроків» перетворюється на «850».

## Тести

Тести з базою працюють з окремою базою, яку передають у `DATABASE_URL`, і щоразу створюють її схему наново:

```bash
set -a; . ./.env; set +a
docker compose run --rm \
  -e DATABASE_URL="postgresql+asyncpg://$POSTGRES_USER:$POSTGRES_PASSWORD@db/lisovyi_test" \
  bot pytest -q -rs
```
